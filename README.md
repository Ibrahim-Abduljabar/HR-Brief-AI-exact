# HR Brief AI — النسخة الخارجية

صفحة هبوط مبنية بـ HTML و CSS لعرض فكرة HR Brief AI للمستخدمين.  
توضح كيف يساعد النظام في تلخيص تقارير الموارد البشرية الطويلة وتحويلها إلى ملخص تنفيذي جاهز.

---

## المحتوى
- تعريف بالمشروع
- عرض المميزات الأساسية
- شرح طريقة عمل النظام
- زر الدخول للنسخة الداخلية
- تصميم عربي خفيف وسريع
